## Construction notes

**N-Back behaviour comes from EEG triggers**, because the behavioural files are
MATLAB tables (MCOS objects) that `scipy.io.loadmat` cannot decode. Logged in
`deviations.md` with its validation and residual risk.

**MATB uses only TRACK and SYSMON.** RESMAN appears from Medium and COMM only
in Difficult, so any index touching them would make Easy incomparable and
manufacture a gradient from absent subtasks (`pitfalls.md` #9). Verified
directly: `MATB_Easy` exposes {TRACK, SYSMON}, `MATB_Med` adds RESMAN. The
container key also varies (`output` vs `MATB_diff.output`), so the struct is
located by its fields rather than by key.

**Band power reuses the P0 covariances.** Those were computed on band-filtered
epochs, so the matrix diagonal is per-channel band power — no reprocessing.
Log-transformed, since band power is approximately log-normal.

**ROI definitions are INTERPRETIVE.** The references name "frontal" and
"posterior" effects without listing channels. Used: frontal = F3, Fz, F4, FCz;
central = C3, C4, CPz; posterior = P3, Pz, P4. CPz is grouped as central
because the posterior alpha effect to be confirmed is parietal. These must be
fixed at G-LOCK.
